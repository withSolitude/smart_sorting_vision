# SAM 3 交互式标注

此入口使用官方单实例正负点分割，不依赖 `inference.prompts` 的文字语义。
可以标完整物体，也可以尝试只选平顶物体的顶面；最终由人确认边界。

本文以原顶部单类配置为例。侧面12类请运行 `run_side_interactive.cmd`，
使用 `sam3_side_config.yaml`，类别自动按形状目录预选，也可在窗口中修改。
侧面完整步骤见 [README_侧面分割预标注.md](README_侧面分割预标注.md)。

## 1. 启动与配置

本机直接双击 `E:\gongxun\27\sam3\run_interactive.cmd`。

也可以在 PowerShell 中运行：

```powershell
cd E:\gongxun\27\sam3
.\run_interactive.cmd
```

从 GitHub 下载后，先按 `README.md` 准备官方源码、本地权重和 Python 环境。
此窗口只增加 Python 标准库 Tkinter，不需要另装 Web 服务。
Windows 本机已经检测到 Tkinter；Linux 若系统 Python 不含 Tkinter，需安装对应的系统包。

仍使用 `sam3_config.yaml` 的 `model`、`dataset`、`export` 配置，另外有：

```yaml
interactive:
  output_dir: outputs_interactive  # 固定目录，可下次继续标注；相对 YAML 所在目录。
  view_width: 1200                 # 最大显示宽度，不改变图像或标签坐标。
  view_height: 820                 # 最大显示高度，受当前屏幕可用尺寸限制。
```

切换数据集改 `dataset.source_dir`；换数据集时同时换一个新的 `interactive.output_dir`。
整物体和顶面两种标注也应分别使用输出目录，避免混在一起。
可以先运行 `run_prelabel.cmd` 自动生成候选，再运行 `run_interactive.cmd` 复核。
默认 `interactive.prelabels_dir: latest` 自动加载当前数据集最近完成的批次；
也可用窗口“加载自动预标注批次……”按钮指定批次目录。侧面对应 `run_side_prelabel.cmd` → `run_side_interactive.cmd`。
候选正确时直接 S/N 确认本张；错误实例选中后 Delete，再点选或手工补标。
已保存的人工标签优先；自动草稿及零检出图片在确认前不会进入交互导出数据集。

首次启动会加载模型，可能等待几十秒；随后每张图编码一次，继续补点会复用缓存。
程序不会因为没有候选而退出，可以重画或用手工多边形。

## 2. 标一个顶面

1. 左键点顶面内部，绿色圆点代表“需要的区域”。
2. 如果侧面也被选中，右键点侧面，红色圆点代表“不要的区域”。
3. 使用右侧 `1 / 2 / 3` 或键盘数字键比较候选。
   候选是同一个目标的不同分割解释，不是三个物体。
4. 可以继续补正点、负点。默认优先展示符合点选要求的候选，再比较预测质量。
   分数高不代表顶侧分界一定正确；提示“有点未满足”时要继续检查。
5. 确认轮廓正确后按 Enter，加入一个实例。
6. 点另一个物体，重复上述步骤。一张图的所有目标确认后按 S 保存。
7. 按 N 保存并进入下一张。

如果一次点选覆盖整件物体，可以先按 B，左键拖动框住目标顶面的大致范围，
松开后生成候选，再补正负点。这里的框属于当前实例的空间提示，
不是旧文字接口里的“寻找相似物体”示例框，也不会强制把结果裁成框内区域。

要修正已确认实例，在右侧列表选中它，按 Delete 删除，再重新标。
S 保存和 N 下一张不会擅自确认正在编辑的候选；先 Enter 确认或 C 清除。
确实没有本任务目标的图片，可以不加实例直接 S 保存，生成空标签。

## 3. 分割不理想时直接描边

1. 按 P 进入手工多边形模式，当前未确认的点/框/候选会清除。
2. 左键沿顶面边缘依次加顶点；圆弧用多个点描出。
3. 右键或 Backspace 撤销最后一个顶点。
4. 按 Enter 自动闭合多边形并加入一个实例。
5. 继续画其他目标，或按 D 回到点选模式。

如果因面积过小无法确认，先检查是否点错位置，再检查 `export.min_area_px`。
缩放仅影响显示，保存的轮廓始终使用原图像素坐标再归一化。

## 4. 快捷键

| 操作 | 按键或鼠标 |
| --- | --- |
| 正点 / 负点 | 点选模式下左键 / 右键 |
| 点选 / 框选 / 手工多边形 | D / B / P |
| 切换候选 | 1 / 2 / 3 |
| 确认当前实例 | Enter |
| 撤销最后一点 | Backspace |
| 清除当前未确认提示 | C |
| 删除列表选中的实例 | Delete |
| 保存本张 | S |
| 保存并下一张 | N |
| 上一张 | A |
| 放大 / 缩小 | 鼠标滚轮，围绕鼠标位置缩放 |
| 平移 | 按住鼠标中键拖动 |
| 适应窗口 | F |
| 导出已保存的数据 | E |

再次打开同一个输出目录会从第一张未保存图片开始；原来的实例仍可返回修改。
如果所有图片都保存过，则从第一张开始复核。

## 5. 保存与训练数据

默认保存到工具目录下：

```text
outputs_interactive/
├─ annotations.json              # 已确认图片与像素多边形，支持恢复
├─ dataset/
│  ├─ data.yaml                  # 训练用数据集配置
│  ├─ classes.txt                # 仍为单类别 object
│  ├─ train.txt / val.txt / test.txt
│  ├─ images/train/图片.jpg
│  └─ labels/train/图片.txt
├─ summary.json                  # 按 E 导出时更新
└─ sam3_interactive_cvat.zip      # make_zip: true 时按 E 生成或更新
```

仅按 S 或 N 明确保存过的图片进入数据集，未标注图片不会自动当成空背景。
图像保持原始字节，源采集目录不会被改写。保留原来的 train/val/test 归属。
标签是类别0的 YOLO 分割多边形，不把三个候选一起写入。

按 E 前先确认或清除本张候选。导出的 ZIP 可以在 CVAT Project 中按
`Ultralytics YOLO Segmentation 1.0` 导入复核。
E 会保存本张已经确认的修改，但不会把尚未操作的新图自动保存为空背景。
继续修改后再按 E，ZIP 才会更新；每次 S 已会更新训练目录和 split 清单。

当前普通 YOLO 单条多边形只保留一个实例的最大连通区域，内孔会填平。
窗口会提示“仅保留主轮廓，需检查”；遮挡导致断开时需要人工判断，不补画隐藏部分。

## 6. 顶面的定义不变

正负点可以帮助指定平顶物体的目标面，但不能保证模型总能分出顶侧界线。
没有清晰分界时使用手工描边。尖端朝上的圆锥、棱锥，以及球体没有平面顶面，
不要随意画尖点周围的小圈或上半球作为统一顶面真值。
交互分割也不提供高度信息，不会自动修正托盘平面映射的透视误差。
