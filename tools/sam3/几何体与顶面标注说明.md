# 几何体与顶面标注说明

## 1. 先区分整物体和顶面

整物体任务：沿每件物体所有可见表面的外边界标注，包括顶面和侧面；不补画被遮挡部分。
顶面任务：只标朝上平面的可见区域，沿顶面与侧面的分界标注；不把阴影当分界。
这两种任务应分别保存数据、训练和输出，不能在同一个 `object` 类里随意混用。

## 2. 按几何体预标注完整物体

将原 YAML 的整个 `inference` 段替换为下段，不要重复添加第二个 `inference`：

```yaml
inference:
  # 候选提示，未验证这些词在整批数据上的准确率；导出仍为 0: object。
  prompts:
    - cube               # 正方体，完整可见轮廓。
    - rectangular prism  # 长方体，完整可见轮廓。
    - cylinder           # 圆柱体，完整可见轮廓。
    - cone               # 圆锥体，完整可见轮廓。
    - truncated cone     # 圆台，完整可见轮廓。
    - pyramid            # 棱锥，完整可见轮廓。
    - prism              # 棱柱，完整可见轮廓。
    - sphere             # 球体，完整可见轮廓。
```

只保留实际存在的物料种类。几何提示也可能漏检或误选机构，不保证比颜色提示准确。
例如此前实际样图上的 `cone` 没有检出，因此先单图试验，再少量批处理。

## 3. 严格顶面任务怎么标

| 物体及姿态 | 标签区域 |
| --- | --- |
| 正方体、长方体稳定放置 | 朝上平面的可见多边形，排除竖直侧面 |
| 直立圆柱 | 上端圆盘在图中的可见投影，常表现为椭圆 |
| 圆台，平端朝上 | 朝上端面的可见投影，不包含圆台侧面 |
| 棱柱，平面朝上 | 预先约定的朝上平面；保持训练与验证的规则一致 |
| 直立圆锥、棱锥，尖端朝上 | 没有有面积的水平顶面；尖点不能作为分割多边形 |
| 球体 | 没有可辨识的平面顶面；不要凭空画圆帽或上半球边界 |
| 圆锥或棱锥倒放，底面朝上 | 若任务允许该姿态，可以标可见的朝上底面 |
| 倒卧圆柱、倒卧锥体、倾斜物体 | 不能套用“直立平顶”的规则，须单独定义姿态处理 |

顶面被部分遮挡时只标可见区域，不用可见部分的质心冒充完整顶面中心。
顶面完全不可见时不猜画。强遮挡可能使一个物体分成多个可见区域；
当前导出器仅保留最大连通区域，需按 `manifest.csv` 的记录人工复核。

用于有平顶物体的 SAM 候选提示可替换为：

```yaml
inference:
  # 只尝试生成平顶候选；最终必须人工确认确实没有包含侧面。
  # 此列表不覆盖尖端朝上的锥体、球体、倒卧或强倾斜物体。
  prompts:
    - top face of a cube               # 正方体朝上平面。
    - top face of a rectangular prism  # 长方体朝上平面。
    - top face of a cylinder           # 直立圆柱上端面。
    - top face of a truncated cone     # 圆台朝上平端面。
    - top face of a prism              # 棱柱朝上平面。
```

SAM 3 不保证按这些词准确区分顶面与侧面，可能输出整物体、侧面或空结果。
需要在 CVAT 等工具里修边，形成一致的人工真值，再训练自己的顶面模型。
框提示也只是示例，不能保证框内结果就是顶面。

## 4. 球和尖锥要怎么办

建议保留原来的完整物体模型识别所有物体，顶面模型只用于有可见平顶的物体。
球、尖锥、倒卧物体需要另外的定位策略；不要把它们的完整轮廓与其他物体的顶面
混成同一类、当成同一种抓取区域处理。

若以后希望单个模型同时输出 `top_face`、`cone`、`pyramid`、`sphere`，
需要明确多类别标签，并同时修改导出器和运行时的处理分支。
当前版本把所有提示统一为 `0: object`，仅修改 prompts 不会实现多类别。

不要用“尖点周围随意画一小圈”或“球体随意取中间一块”作为顶面标签。
这些边界在图像中没有一致的物理定义，会让标注与抓取语义不稳定。

## 5. 实际操作顺序

1. 保留当前整物体标签，顶面候选与人工修订结果另存，避免覆盖。
2. 先挑选中心、四边、不同姿态、遮挡与堆叠的代表图；固定上述标注规则。
3. 单图比较几何体提示与顶面提示，再用 `--limit 5` 少量批处理。
4. 人工删误检、修顶侧分界、拆相邻实例、补漏检；空结果不能直接当真实空背景。
5. 检查训练集和验证集使用同样规则，再训练并看实际抓取误差。

在 PowerShell、工具所在目录中测试：

```powershell
.\.venv_sam3\Scripts\python.exe test_sam3.py "你的测试图片.jpg" --prompt "cylinder" --show
.\.venv_sam3\Scripts\python.exe test_sam3.py "你的测试图片.jpg" --prompt "top face of a cylinder" --show
```

顶面数据可将 YAML 里的 `dataset.output_dir` 改成 `outputs_top_surface`，
其余 dataset 字段保留。只改输出目录不会改变分割语义或标签类别。

## 6. 顶面模型能解决到哪一步

正确识别顶面可以减少把侧面算进物体中心的问题，但不会自动补偿物体高度。
当前像素到机器人坐标使用托盘平面的二维映射；高于托盘的点仍可能出现透视偏差。
球的轮廓中心、尖锥的尖点、被遮挡顶面的可见区域中心，都不能直接视为已求出的
正确机器人抓取坐标。图像标注、抓取点定义和空间坐标换算是分别需要验证的步骤。
