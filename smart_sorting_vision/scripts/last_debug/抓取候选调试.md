# 多抓取点与方向调试

在包含 `scripts`、`vision`、`config` 的视觉工程目录运行：

```bash
python -m scripts.last_debug.test_single_object_grasp
```

启动会打印实际代码路径、YAML 路径、`GEOMETRIC GRASP` 参数和 `FINGER COLLISION` 开关。
正式参数统一在 `config/runtime_config.yaml`。当前不做高度透视补偿，不改变相机和机械标定。

## 画面和按键

- 绿色轮廓：YOLO 完整实例轮廓。
- 蓝色十字：完整轮廓质心。
- 橙色点及文字：实际进入联合规划的候选点和来源。
- 绿色十字：最终选中的抓取点；方向箭头显示闭合轴及夹指纵向轴。
- `I`：打印候选点、选中来源、XY、Yaw、宽度、预开口和两侧接触偏心量。
- `S`：保存当前标注图；`P` 暂停，`R` 重置共识并恢复自动选择。
- `[` / `]`：切换预览物体。
- `Space`：对 READY 共识目标执行一次实抓。手动预览其他物体时会阻止实抓，按 `R` 恢复。

来源含义：`inscribed_peak` 为局部最大内接圆，`opposing_edges` 为对侧边接触中点，
`support_midpoint` 为边与顶点等其它支撑对的中点，
`axis_section` 为主轴厚截面，`ellipse_center` 为椭圆拟合中心，
`polygon_center` / `box_center` 为轮廓质心 / 最小外接矩形中心。

## 当前选择逻辑

保留完整轮廓，不再整体内缩。每个物体生成有限的点，再分别检查多个真实支撑方向。
矩形两组方向都参与，安全相近时优先较小开口，即夹指接触长边、沿短轴闭合。
近圆轮廓尝试若干闭合方向；锥形二维轮廓沿厚截面生成点，避开尖端。

宽度取实际夹指纵向覆盖带内的截面；完整目标仍检查夹指侵入，邻物和边界检查使用实际夹指包络。
无合法点和方向时，流水线返回本帧无候选，交给上层继续识别。
`parallel`、`round`、`tapered`、`general` 仅描述二维轮廓，不是真实三维形状分类或顶面识别。

## 参数调整

新模式由 `vision.top.geometric_grasp.enabled` 控制，与旧 `grasp_search` 微调开关独立。
启用时有限的点×方向会比较一次，不重复旧角度/位移搜索。`grasp_orientation.enabled`
仍控制是否规划动态方向。`gripper_collision.enabled` 当前已开启，用于真实夹指空间检查。

- `max_points`、`max_directions`、`max_pose_trials`：候选数量和计算量上限。
- `min_spacing_px`：点太密时增大；候选太少时适当减小。
- `min_radius_ratio`：越大越偏向厚截面；不是整体内缩比例。
- `axis_sample_fractions`：主轴上的额外采样位置，相对中心按轴全长比例偏移。
- `round_yaw_offsets_deg`：圆形轮廓尝试的方向。
- `width_penalty_per_mm`：增大后更偏向小开口，只在优先夹长边时生效。
- `balance_penalty_per_mm`：增大后更偏向两侧同时接触的居中点。

先用单个长方体确认长边、方向和开口，再在旁边放一个邻物，观察是否换点或方向。
最后测试锥形、圆形和堆叠。二维插入通道检查不能判断被遮挡物体的真实上下关系。
