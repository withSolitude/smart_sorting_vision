# 抓取点向外补偿

在 `config/runtime_config.yaml` 的 `vision.top.outward_radial_compensation` 调整：

```yaml
enabled: true
gain: 0.02
max_shift_px: 20.0
center_full_px: null
```

只修改 YAML，不需要改代码。位移为“离补偿中心的距离 × gain”，仅向外，
超过 `max_shift_px` 时沿同一方向限幅。负系数直接报配置错误；`gain: 0` 或 `enabled: false` 可对比原点。

`center_full_px: null` 使用去畸变内参 `new_camera_matrix` 的主点，适用于近垂直顶部相机。
如果已有实测相机垂足，可以填写 `[x, y]`，坐标必须属于完整去畸变图。
程序自动减当前 `camera.top.safe_roi` 起点，修改 ROI 不需要重新填写中心。
不要将 ROI 几何中心当作相机中心。

运行：

```bash
python -m scripts.last_debug.test_single_object_grasp
```

启动会打印实际代码和 YAML 路径、开关、系数、中心与位移上限。
画面中橙色十字为原始抓点，绿色十字为补偿后抓点，箭头表示向外补偿；
青色标记为补偿中心（位于当前画面内时显示）。按 `I` 打印原点、新点和实际位移；`S` 保存画面。

先固定夹爪Yaw，用同一个物体放在中心、四边/四角比较。默认0.02只是调试初值，
可从0、0.01、0.02逐步比较实际对心，增加系数会增加向外位移。

原抓长边、方向算法保持不变。补偿在方向和局部偏移求完后只应用一次；
正式机械XY、预开口、夹指检查与预览共用新点，`Space` 不会再补一次。
若新点超出目标、安全区域、机械行程，或夹指接触检查不通过，该候选会被拒绝；
可减小系数，终端的拒绝原因可辅助定位。不会自动改成向内补偿。

离线几何回归：`python -m tests.test_outward_radial_compensation`。
