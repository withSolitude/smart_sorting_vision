# 顶部抓取的实体包络选轴

本次替换“4像素内邻物中心连线决定闭合轴”的规则。每个自然抓取族使用自己的抓取点、真实执行Yaw和动态预开口，检查双指实体位置及从预开口闭合到目标支撑面的二维扫掠。目标本身不作为障碍，所有其他分割实例都参与检查，不再只看是否贴合或邻物中心朝向。

方块、长方形存在两组相对平行边时，会分别比较这两条自然轴。不会为了转90°而强制给所有形状生成一条不符合其接触几何的轴。换轴时也切换该族的抓取点，局部位移与径向补偿在此基础上应用。

## 开关与旧配置兼容

在 `vision.top.gripper_collision` 中新增：

```yaml
gripper_collision:
  enabled: false
  axis_selection:
    enabled: true
```

这两个开关相互独立：

| axis_selection.enabled | gripper_collision.enabled | 执行检查 |
|---|---|---|
| true | false | 名义实体和闭合扫掠；超出重叠面积容差的实体相交会拒绝该轴，额外间隙用于评分 |
| true | true | 先检查名义实体和闭合扫掠，再执行原有完整安全余量碰撞检查和硬性最小间隙检查 |
| false | true | 关闭新增名义检查，保留原有完整安全余量检查 |
| false | false | 两种包络检查都关闭 |

旧现场配置没有 `axis_selection` 段时默认启用；只接受布尔值 `true/false`，字符串 `"false"`、数值和空值会在加载配置时明确报错。无需用仓库的整份 YAML 覆盖已调好的现场配置。

名义检查不会把 `object_margin_mm`、`opening_uncertainty_mm` 和 `wall_margin_mm` 加到实体上，也不会仅因 `hard_min_clearance_mm` 未达到就拒抓。实际剩余间隙参与原有 `preferred_clearance_mm` 评分；完整碰撞开关打开时，原有更严格的余量和硬间隙规则继续生效。

同一物体的两条轴都发生实体重叠时，跳过该物体、继续检查其他物体。所有目标都没有实体空间时不能强制输出碰撞抓取。前置安全抓点规划、机械工作区、边缘Yaw限制和目标接触检查仍会拒绝不合格的候选。

## 与多姿态搜索的关系

`axis_selection.enabled=true` 时，即使 `grasp_search.enabled=false`，仍比较各自然抓取族的零偏移姿态。

开启多姿态搜索后，优先走自然轴快速路径；只有整帧没有可行候选时，才读取 `yaw_offsets_deg`、`longitudinal_offsets_mm` 和 `closing_offsets_mm` 进行完整搜索。因此现场配置 `[0, 90, -15]` 不代表每次夹取都会按这三个偏角执行。方块的另一个约90°自然轴来自其平行边几何，不依赖配置中是否写了90。

启动日志会分别显示完整碰撞检查、名义选轴检查和多姿态搜索的状态，避免 `collision=false` 时误以为搜索也关闭。

## 现场验证

先保留实测高成功率配置中的预开口总余量8mm、径向补偿、标定、搜索偏移和物体顺序权重。8mm总余量在居中时相当于每侧4mm，不是每侧5mm。本次仓库配置只增加新开关和修正文案，不替换这些数值。

对同一布局分别记录：干净取出、取出但邻物位移、空抓、无可行候选。先用两个对齐方块，再用错位方块、窄缝、长条邻物和密集混排；不要用已经被上一轮挤开的布局直接比较成功率。关闭 `axis_selection.enabled` 可以对照新增名义检查；完整复现旧方案需保留旧代码版本，因为关闭此开关不会恢复已删除的中心连线规则。

当前 `finger_length_mm=5.0`、`finger_thickness_mm=2.7` 是现用配置值，必须实测核实与邻物同高、实际参与碰撞的夹指截面；不能只量夹指最尖端，也不能把整套机构最高处的投影直接代替该截面。`object_overlap_tolerance_px` 是允许重叠的像素个数（面积），不是允许穿入的线性距离。

本模型是二维估计，尚不包含物高、Z运动侧偏、低位Yaw旋转、提起和转运扫掠。名义选轴能减少建模范围内的干涉，现场还需按实际夹指尺寸、定位误差和动作阶段验证。
