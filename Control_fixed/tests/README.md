# Emm V5 / CoreXY 主机回归

在工程根目录用 PowerShell 执行：

```powershell
.\tests\run_host_tests.ps1
```

要求 PATH 中有支持 C++17 的 `g++`。测试脚本将真实电机驱动和 XY 协调器与
`tests/host/` 的 HAL/CAN 替身链接，不连接或驱动实物。编译使用
`-Wall -Wextra -Werror`，可执行文件输出到 `tests/.build/`。

测试覆盖：

- Emm V5 扩展 CAN ID、FD 两包内容、正负号、数值边界和双帧 FIFO 预检查。
- 31/32/35/36/3A 解析、应答、错误包和标准帧/错误地址过滤。
- 31 单圈正反向跨圈累计、丢包超时和恰好半圈歧义锁定；36 多圈位置独立有效。
- 当前0°现场方向的 CoreXY 矩阵及逆变换、反馈与指令不同量纲的换算。
- 上电双轴停止确认、人工原点前禁止运动、工作区/速度输入约束。
- 两台电机应答后广播同步、地址1同步应答、真实位置/速度/状态稳定后到位。
- 缺电机应答、缺同步应答、拒绝控制命令、协议错误、反馈掉线、编码器跳变、堵转。
- STOP 遇 CAN BUSY 自动重试、FE/E2 必须伴随新禁用及静止反馈才能确认停止。
- XY控制帧走CAN2；重复STOP保留已验证的停稳状态，新运动或反馈过期后仍重新确认。
- 单独再次编译默认未标定配置，确认可读反馈和停车，但拒绝原点确认及运动。

这些测试验证协议编码、软件状态机和数学换算，不能代替电机方向、带轮传动尺度、
机械原点、工作区及总线接线的实机标定。`XY_TEST_CALIBRATED` 只作用于同时定义
`EMM_V5_HOST_TEST` 的测试程序，不会解除正常 STM32 固件的标定锁。

另有 `integration_tests.cpp` 编译工程中真实的 `holding_jaw.cpp` 和
`sorting_storage.cpp`，以 `integration_support/` 中的设备替身控制异步 XY、
CAN 反馈和 UART BUSY。该独立程序不会替换或编译进固件，覆盖：

- XY BUSY 重试和真实到位前不进入夹爪后续动作。
- 待机必须核对真实坐标与舵机完成时间；回程先抬升，再平移，再松爪。
- 故障不松爪，舵机 STOP 遇 UART BUSY 持续重试，实测停稳与可重新开工分离。
- 输出提交有截止时间，避免整机永久等待。
- 分箱对位、翻盘、回位全部完成后，完成事件仅消费一次。
- 输出轴或普通速度/状态反馈任何一路陈旧时均不能用旧位置误判完成。
- 重复 STOP 不重置回程；故障恢复须安全回位后显式确认。
- 同一 CAN1 上的 Emm 扩展帧、远程帧不能送进 DM4310 解析器。
- 达妙输出轴方向反转时，位置反馈和最终力矩使用一致的方向约定。
- 独立 Yaw 标定及停止不能伪造待机就绪，必须恢复完整待机姿态。
- 储物故障禁止底层 Alive 自动清错/使能，只有显式 STOP 授权后才可安全恢复。

`handshake_tests.cpp` 还编译真实的 `ita_sorting_handshake.cpp`，仅替换通信对象
的收发函数，覆盖独立储物测试与标定/启动互斥、STOP 清除排队事务、
接收与完成通知遇 TX BUSY 时保留事务、重复命令不重复执行以及逐件预开口参数清理。
还覆盖故障与显式 STOP 同周期到来时保留恢复请求，以及 ERROR 通知发送忙时重试并禁止提前 START。

`robot_tests.cpp` 将真实 Robot、Handshake、HoldingJaw 和 SortingStorage 一同编译，
只替换硬件设备和通信收发，验证 XY 标定完成后的 START 必须先真实回待机、
XY 故障但已停稳时可回复 STOP 而不能自动重新开工，以及储物完成遇发送忙保留事件。

目前共 13 组驱动/XY 动态回归、1 组默认标定锁回归、11 组机械上层动态回归、
7 组通信握手动态回归和 3 组整机调度联合回归，共 35 组。
